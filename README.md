# \# Registration

# 

# A Java console application for Part 1 of the PoE — a registration and login feature for a chat app.

# 

# \## Features

# \- Register a user with a username, password, and South African cell phone number

# \- Validates:

# &#x20; - Username contains an underscore and is no more than 5 characters

# &#x20; - Password is at least 8 characters with a capital letter, a number, and a special character

# &#x20; - Cell phone number includes the +27 international code

# \- Login with a registered username and password

# \- Includes JUnit unit tests for all validation and login logic

# 

# \## How to run

# Open the project in NetBeans and run `Registration.java`.
